# 台股研究

自動研究台股個股與 ETF，產出單頁 HTML 報告，內容包括：

- 今日合理價區間
- 12 個月後保守、中性、樂觀三種情境的價格與機率，以及機率加權的期望價與上下檔比
- 期中檢查點：12 個月內可觀察的里程碑，用來追蹤判斷是否成立
- 會影響估值的市場消息與事件，各自附上機率和對合理價的影響

## 使用方式

在專案資料夾開啟 Claude Code，直接說：

```text
研究 8936
研究 0050 00679B 00713 009826 8936 7584
繼續研究 0050 00713     ← 額度不足暫停後接續
```

接下來不需要切換到 Codex，也不需要再下指令。完成後 Claude 會回報每一檔的結論與報告位置：`報告/<代號>/<研究日>.html`，可以直接用瀏覽器離線開啟。發布報告時，腳本也會一併更新上方的「最新報告」清單。

## 網頁發布

`報告/` 推送到 `dev` 後，GitHub Actions（[`.github/workflows/pages.yml`](.github/workflows/pages.yml)）會自動發布到 GitHub Pages，網址為 `https://yinweli.github.io/Finance/<代號>/<研究日>.html`。網站是公開的，研究報告依規則不寫個人持倉或帳戶資訊。

操作意見也是單頁網頁，放在 `報告/意見/<日期>-<主題>.html`，網址為 `https://yinweli.github.io/Finance/意見/<日期>-<主題>.html`。意見會寫到持股與現金，推送後同樣公開。產生方式：

```powershell
python -X utf8 -B 工具/opinion.py .tmp/工作/意見/<日期>-<主題>.md
```

需要手動重建清單時執行：

```powershell
python -X utf8 -B 工具/readme.py
```

也可以不經過 Claude，直接在終端機執行：

```powershell
python -X utf8 -B 工具/run.py 8936
```

## 流程

```text
腳本抓資料 ─→ Claude 補充法說與新聞 ─→ Codex 撰寫草稿 ─→ Claude 審查修正 ─→ 腳本產生報告
```

- 行情、財報、月營收、三大法人、融資融券、集保、大盤、匯率與美債殖利率都由腳本從官方來源抓取，AI 只讀精簡過的摘要。
- Codex 不能上網，只能根據工作夾內的資料撰寫，所以每個數字都查得到出處。
- 每一步都有格式檢查與自動重試。額度不足時整批暫停，之後可從中斷處接續。

詳細規則見[研究流程](流程/研究流程.md)。
