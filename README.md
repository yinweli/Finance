# 個人財務研究

這個專案結合個人財務報表與研究當下可查證的經濟及市場資料，協助評估生活支出、投資加碼與退休準備。研究結果整理成可離線閱讀的繁體中文 HTML 報告。

## 研究主題

| 主題 | 要回答的問題 | 提示詞 |
| --- | --- | --- |
| 生活支出 | 維持目前生活一年需要多少錢？哪些支出增加最多？ | [生活支出研究](提示詞/生活支出研究.md) |
| 投資加碼 | 現價是否有足夠折讓？未來 12 個月有哪些可能結果？什麼情況需要重估？ | [加碼研究共通規則](提示詞/加碼研究共通.md)及各標的提示詞 |
| 退休準備 | 能否在目標年齡退休？退休後的現金流是否足夠？若有缺口，先調整什麼？ | [退休準備研究](提示詞/退休準備研究.md) |

## 開始研究

1. 在專案資料夾中開啟 Codex 或 Claude Code，用標的代號、提示詞名稱或研究問題指定範圍。股票與股票 ETF 優先使用 OpenAI Public Equity Investing，安裝、呼叫與備援方式見[研究流程](工具/研究流程.md)。
2. 首次研究由助理查核公開資料、建立估值和情境。已有可重算快照時，先比對最新資料與上次論點，再更新受影響的部分。
3. 研究資料交給本機程式計算、驗證及渲染。完成的報告存入 [報告](報告/)，可直接在瀏覽器開啟。同日重跑或更正會另存版本。

```text
請首次完整研究 8936，保留四年季度模型，輸出離線 HTML。
請更新 0050 加碼研究，說明資料與結論有何變化。
請用「生活支出研究」分析最近三個完整年度的支出。
請用「退休準備研究」比較目標退休年齡下的基準與不利情境。
```
