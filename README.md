# 個人財務研究

這個專案結合個人財務報表與研究當下可查證的經濟及市場資料，協助評估生活支出、投資加碼與退休準備。研究結果整理成可離線閱讀的繁體中文 HTML 報告。

## 研究主題

| 主題 | 要回答的問題 | 提示詞 |
| --- | --- | --- |
| 生活支出 | 維持目前生活一年需要多少錢？哪些支出增加最多？ | [生活支出研究](提示詞/生活支出研究.md) |
| 投資加碼 | 現價是否有足夠折讓？未來 12 個月有哪些可能結果？什麼情況需要重估？ | [加碼研究共通規則](提示詞/加碼研究共通.md)及各標的提示詞 |
| 退休準備 | 能否在目標年齡退休？退休後的現金流是否足夠？若有缺口，先調整什麼？ | [退休準備研究](提示詞/退休準備研究.md) |

## 開始研究

1. 在專案資料夾中開啟 Codex 或 Claude Code，用標的代號、提示詞名稱或研究問題指定範圍。股票與股票 ETF 優先使用 OpenAI Public Equity Investing，安裝、呼叫與備援方式見[研究流程](工具/研究流程.md)。
2. 首次研究由助理查核公開資料、建立估值和情境。已有可重算快照時，先比對最新資料與上次論點，再更新受影響的部分。
3. 研究資料交給本機程式計算、驗證及渲染，先在 `.tmp/工作/` 產出草稿與交接檔。
4. 換另一位助理審查，意見寫在同一個工作夾。沒有問題時由審查者發布到 [報告](報告/)；有問題時交回研究者修正，審查者複核後再發布。報告可直接在瀏覽器開啟，同日重跑或更正會另存版本。交接與審查規則見[研究流程](工具/研究流程.md#工作夾與交接)與[審查流程](工具/審查流程.md)。

```text
Codex：請首次完整研究 8936，保留四年季度模型。
Claude Code：審查 8936。
Codex：修正 8936。（審查有意見時）
Claude Code：審查 8936。（複核並發布）

請更新 0050 加碼研究，說明資料與結論有何變化。
請用「生活支出研究」分析最近三個完整年度的支出，不需審查。
```

## 專案內容

- [專案指引](AGENTS.md) 供 Codex 與 Claude Code 共用。財務試算表僅按需唯讀，經明確指示才可修改。
- [提示詞](提示詞/) 保存台灣市場與各標的的研究口徑，以及生活支出與退休的研究方法。
- [工具](工具/) 包含[研究流程](工具/研究流程.md)、[資料格式](工具/研究資料.md)、固定資料抓取工具和 HTML 產生器。研究與格式驗證共用同一份資料。
- [版型](版型/) 保存離線報告的樣式與互動程式。
- [測試](測試/) 使用固定資料，可執行 `python -X utf8 -B -m unittest discover -s 測試 -v`。
