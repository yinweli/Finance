# 研究台股標的

使用者只需要下一次指令，整個流程由腳本串接 Claude 與 Codex 自動完成。你的工作只有啟動、等待和回報，不要自己研究或改寫報告。

## 步驟

1. 從使用者的話取出代號，保留使用者給的順序。使用者說「重做」或「從頭」時加上 `--restart`。
2. 在背景執行（`run_in_background: true`），等完成通知，不要輪詢輸出檔：

   ```powershell
   python -X utf8 -B 工具/run.py <代號1> <代號2> ...
   ```

   一檔通常需要 15～40 分鐘，第一次抓取籌碼資料會更久。
3. 完成後只讀輸出最後的「## 研究結果」區段，用繁體中文回報每一檔的：
   - 結論一句話
   - 現價、合理區間、12 個月的機率加權期望價
   - 報告路徑（`報告/<代號>/<研究日>.html`）
4. 依結束碼處理：
   - `0`：全部完成。
   - `1`：部分標的「待人工」。說明卡在哪一步與原因，工作夾的 `紀錄/` 有完整輸出。問使用者要重跑，還是要你查原因。
   - `2`：額度不足，整批暫停。告訴使用者額度恢復後說「繼續研究」，就用相同代號再執行一次，會從中斷處接續。

## 注意

- 不要讀 `資料/`、`草稿.md` 或 `紀錄/` 的全文，除非使用者要你查問題。
- 不要修改 `報告/` 中已發布的檔案。
- 使用者要比較或解釋報告內容時，讀報告內嵌的 `research-data` 或工作夾的 `定稿.md`，不要讀整份 HTML。
