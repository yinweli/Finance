# 7584 樂意｜遊戲營運與加碼研究

```text
依 CLAUDE.md 與 提示詞/加碼研究共通.md，研究 7584 樂意傳播的合理價與加碼條件。估算既有遊戲的獲利，反推新品與自研要做到什麼程度才能支撐現價。優先查公開資訊觀測站、公司財報與法說、官方遊戲公告及櫃買中心。

1. 對照主要遊戲上線、改版、續約、停運與併購事件、月營收，以及單季營收、毛利、營業利益、歸母淨利、稀釋 EPS 和現金流。區分原有業務、併購與一次性項目。興櫃與上櫃分段呈現股價和量能。
2. 以遊戲生命週期建模，分列既有遊戲、已公告代理新品、自研及授權項目，標示地區與子公司。估計舊遊戲衰退、新品上線、首發收入與留存，納入權利金分潤、行銷、研發和減損。未揭露單款收入或留存時，列旁證和估算範圍。
3. 三情境逐季列營收、營業利益率、歸母淨利、稀釋 EPS 和自由現金流。說明合併與歸母淨利、股本和稀釋的換算。反推維持獲利所需的新品收入及支撐現價的可持續獲利。以常態獲利選主要估值法，用現金流交叉核對。分別量化獲利與倍數變動的影響。
4. 三項重估條件涵蓋舊遊戲衰退、新品上線後的營運表現，以及行銷、研發或海外業務的成本與獲利。如要求加碼試算，依新品上線後的營收與獲利確認分批，列成交量、持股比重及不利情境損失。
```
