# 退休準備研究提示詞

```text
請依本專案的 CLAUDE.md，研究我能否在目標年齡退休、退休後的現金流能否支應預計支出，以及如果有缺口，優先調整哪一項最有效。以唯讀方式使用《財務｜退休》和《財務｜生活》。需要核對投資部位或資產配置時，再查《財務｜股票》。

以執行日可查證的最新資料為基準，列出各報表的分頁、資料期間和資產估值日。退休年齡、推估到的年齡和其他假設以我本次指定的條件為優先，其餘沿用《財務｜退休》可核對的參數。只有缺少的資訊可能改變判斷時，才向我確認。等待回答期間，先核對已有資料。

1. 核對資產、負債與收入。從年度資產、退休進度、提領、參數和保險資料整理目前的資產、負債、每年可新增的儲蓄，以及退休後可領的收入。標明資產何時可動用。勞保、勞退、保險或其他給付按實際或可查證的請領時間列入，區分一次領取與定期收入。跨表核對相同資產和給付，避免重複計入。

2. 用實際生活費校正退休支出。用《財務｜生活》的支出紀錄核對《財務｜退休》的退休預算。整理平常開銷、定期但低頻的支出，以及退休後預計增加或減少的項目。列出居住、醫療或照護等可能造成差異的大筆費用，說明金額、起始時間和估算依據。

3. 逐年試算退休前後的現金流。列出通膨、投資報酬、退休年齡、提領方式和推估終點，說明假設來源與日期。從目前推算到目標退休年齡，再逐年估算退休後的收入、支出、淨提領及期末可動用資產。投資報酬若已含配息，避免重複計入。依逐年收支和提領假設反推退休時所需的資產，說明算法，並和屆時預計可動用的資產比較。若出現短缺，列出首次短缺的年份及當年差額。若推估期內都能支應，列出期末資產。比較表採一致的購買力口徑，註明基準年或名目金額的年份。

4. 比較基準與不利情境。用相同的退休目標與提領規則，比較基準情境與退休初期報酬不佳、通膨偏高或醫療照護支出增加的不利情境。說明各項假設調整多少，以及哪一項對資產差額或首次短缺年份影響最大。涉及物價、利率或給付規則時，核對官方資料並註明日期。

5. 比較可行的調整。以維持原計畫為對照，比較延後退休、增加退休前每年儲蓄和調整退休支出。用相同的基準與不利情境試算各方案，量化它們能縮小多少缺口或增加多少餘裕，以及需要付出的代價。依影響和可行性排出優先順序。

以繁體中文 Markdown 交付，金額以新臺幣表示。開頭先回答目標退休年齡是否可行、預計資產比所需金額多或少多少，以及優先做什麼。接著列出支出核對、情境與方案比較、關鍵假設及資料缺漏。結尾說明哪些變化值得重做試算。依 CLAUDE.md 的存檔規則保存去識別化的研究摘要。
```
