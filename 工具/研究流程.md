# 研究流程

研究助理查核證據、決定假設並解釋結果。使用[研究資料格式](研究資料.md)交給本機工具計算、驗證及輸出。依任務載入共通規則、標的研究重點及必要的官方 Skill。

## 選擇研究方法

| 研究工作 | 主方法 |
| --- | --- |
| 首次完整研究股票 | `initiating-coverage`，按研究問題支援估值或預測 |
| 新財報、法說或指引 | `earnings-deep-dive`，說明公告如何改變投資論點 |
| 把新實績併入既有模型 | `equity-model-update`，核對公式、實績、估計及差異 |
| 定期追蹤投資論點或風險 | `thesis-tracker`，檢查既有證據、反證、觀察日期及重估門檻 |
| 重新設計情境或敏感度 | `scenario-sensitivity-generator` |
| 財報口徑需整理、重大模型重建或對外審閱 | 依序對應 `financials-normalizer`、`model-audit-tieout`、`deck-report-qc`，按需選用 |
| 股票 ETF | 採官方 ETF／指數研究視角，由 Finance 標的規則決定成分股估值、配息、追蹤及幣別口徑，依問題選情境、追蹤或資料整理 Skill |
| 債券 ETF、生活支出、退休準備 | 採對應的 Finance 提示詞。00679B 使用利率、存續期間、凸性、匯率及現金流模型 |

公開股票研究以[官方入口](https://github.com/openai/plugins/blob/main/plugins/public-equity-investing/skills/public-equity-investing/SKILL.md)與[路由](https://github.com/openai/plugins/blob/main/plugins/public-equity-investing/shared/plugin-routing-playbook.md)為準。依問題選一個主 Skill，再按官方要求載入支援模組。實際使用時記錄 Skill 及套件版本。研究的交付物為單一離線 HTML。

### Codex 與 Claude Code

- 在 Codex 桌面版的 Plugins 或 CLI 的 `/plugins` 搜尋 **Public Equity Investing**。CLI 可使用 `codex plugin add public-equity-investing@openai-curated`。安裝後開啟新工作階段，選取 `@public-equity-investing` 或已安裝的對應 Skill。套件和資料的實際權限視帳號、工作區和環境而定。[OpenAI Plugins 指南](https://learn.chatgpt.com/docs/plugins)
- Claude Code 透過 `CLAUDE.md` 匯入 `AGENTS.md`。Public Equity Investing 官方發布的是 Codex 套件。Claude Code 以及無法使用 Plugin 的 Codex 可採下列備援。官方套件由原發布管道維護。[Claude Code 專案規則](https://code.claude.com/docs/en/memory)
- **備援**依研究問題和資產類型選 Finance 規則，直接查原始公告、財報、行情或指數資料。先對齊日期和口徑，再整理實績、假設、估值與獨立交叉核對。列出情境、證據限制、投資論點、反證和可觀察的重估條件。股票 ETF 用成分股與指數資料，債券 ETF 用債券利率與現金流。股票或股票 ETF 的備援快照以 `method.mode` 記為 `fallback`，交代實際可用資料。若關鍵資料缺失，限縮可支持的結論並標明缺口。
- 研究只取本次必要且已授權的唯讀資料。先採公開正式資料，再按需選已授權的來源。保留來源日期和口徑。禁止自動交易、下單或自行啟用付費服務。

## 首次完整研究

1. 確認代號、交易所、資產類型、研究基準日和範圍。沒有有效快照或使用者要求重做時，執行完整研究。
2. 選擇研究方法，查核官方或已獲授權的原始資料。個股與 ETF 遵守[加碼研究共通規則](../提示詞/加碼研究共通.md)及標的要求。新增標的可直接依資產類型研究，有持續使用價值的標的規則可整理到 `提示詞/`。
3. 建立 `.tmp/研究.json`，把資料時點、數值、假設、公式、來源及結論存成結構化資料。可請助理執行完整流程。
4. 驗證並產出報告。交付 HTML 路徑，摘要指出主要結論及限制。

```powershell
python -X utf8 -B 工具/research_report.py validate .tmp/研究.json
python -X utf8 -B 工具/research_report.py render .tmp/研究.json
python -X utf8 -B 工具/research_report.py verify '報告/YYYY-MM-DD-研究主題.html'
```

## 增量更新

1. 按交易所、代號和主題找最新可重算快照。先擷取上次基準、重估條件和本次相關欄位。舊版 `research-data` 可擷取。沒有快照或欄位不足時，只針對有來源、日期及口徑的舊表格補建基線，缺項須重新查證。
2. 查當期可核對的行情、淨值、匯率或公告，比對有意義的變化。行情更新通常直接重算折溢價、估值位置和情境報酬。新財報、換股、重大營運事件或重估門檻若改變基本面，擴大查核，重做受影響的模型、敏感度及風險判斷。
3. 把已核對的差異寫成更新 JSON。保留未受影響的歷史來源和分析。檢查首頁、附註、圖表、論點與反證提到的時點和數字，說明論點維持、調整或失效的原因。
4. 合併、重算並輸出新版完整 HTML。首版命名為 `報告/YYYY-MM-DD-研究主題.html`。同日重跑或更正依序使用 `-v2`、`-v3`，原檔留存。更正說明放在 `update.changes`。

```powershell
python -X utf8 -B 工具/research_report.py latest --ticker 0050 --exchange TWSE --subject 0050加碼研究
python -X utf8 -B 工具/research_report.py extract '報告/YYYY-MM-DD-0050加碼研究.html' --field input.price --field review --field thesis
python -X utf8 -B 工具/research_report.py update .tmp/更新.json --ticker 0050 --exchange TWSE --subject 0050加碼研究
```

`update` 也可用 `--base 路徑` 指定快照。發布前確認已查核來源和論點，核對圖表、表格及快照的數字，並以離線瀏覽器檢查互動和範圍較寬的表格。
