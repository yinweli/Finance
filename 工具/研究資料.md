# 研究資料格式

用 UTF-8 JSON 提供研究資料。`schema_version` 填 `1`。保留可重算的去識別化輸入與分析，成品會將它們內嵌成 `research-data`。個人試算表只提供完成分析所需的資訊，原始資料、連結、持倉或可識別明細留在原處。

## 頂層欄位

| 欄位 | 填寫方式 |
| --- | --- |
| `subject`、`as_of` | 研究主題與完成日，例如 `0050加碼研究`、`2026-01-10` |
| `asset_type` | `stock`、`equity_etf`、`bond_etf`、`spending` 或 `retirement` |
| `ticker`、`exchange`、`valuation_at` | 市場研究必填。識別市場及代號，估值時點須含時區 |
| `data_cutoff` | 可用資料的截止時間，須含時區 |
| `method` | 官方套件採 `{"mode":"plugin","skill":"initiating-coverage","version":"0.1.31"}`。Finance 原有流程用 `finance`，股票備援用 `fallback`，兩者皆填 `detail` |
| `source` | 來源 ID 對應 `name`、`data_date` 和公開 `url` 或 `locator`。可加 `published_at`、文件頁碼及表格位置。私人報表引用用去識別化的名稱與位置 |
| `input`、`assumption` | 以穩定的英數 ID 保存實績和假設。每筆含 `value`、`unit`、`kind`、`date`，可加 `observed_at`（含時區）、`label`、`note`、`source` 來源 ID 陣列 |
| `formula` | 計算 ID 對應 `op`、`args`、`unit`。參數可引用其他數值 ID。程式計算 `result` 並保留輸入所引用的來源 |
| `conclusion`、`metrics` | 一句結論與頁首指標，`metrics` 以顯示名稱對應數值 ID |
| `valuation` | 市場研究填 `as_of_price`、`fair` 數值 ID、`method` 和 `cross_check` 說明。區間另填 `fair_high` |
| `scenarios` | 市場研究須有 `bear`、`base`、`bull`。各填 `price`、`distribution`、`return` 數值 ID、`end_date` 和 `summary`。區間另填 `price_high` 和 `return_high` |
| `thesis`、`events`、`review` | 市場論點填 `view` 與 `counter`。事件含 `date`、`title`、`status`、`source`，可加 `note`。檢視條件填 `trigger` 和 `action`，首筆顯示在頁首 |
| `sections`、`limits` | 正文區塊與限制清單。敏感度通常用表格與文字呈現，相關變數由公式計算 |
| `update` | 增量填 `changes` 清單、`thesis`（`unchanged`、`revised`、`invalidated` 或 `not_applicable`）和 `reason`。工具寫入前版檔名和日期 |

`kind` 與事件 `status` 可用 `verified`、`guidance`、`consensus`、`assumption` 或 `unverified`。前三者須有可核對來源。待核實數值用 `null` 並說明影響。使用代理值時，另列一筆有依據的 `assumption`。行情、淨值、持倉與財報若時點不同，分別保存，並在 `note` 註明價格類型、期間或評價口徑。日期欄用 ISO 日期，需精確到時間的欄位包含時區。

## 計算與呈現

以下為欄位片段，數值為固定示例。

```json
{
  "source": {"close": {"name": "行情來源", "url": "https://example.org/fixture", "data_date": "2026-01-09"}},
  "input": {
    "price": {"value": 100, "unit": "元", "kind": "verified", "date": "2026-01-09", "source": ["close"]},
    "nav": {"value": 101, "unit": "元", "kind": "verified", "date": "2026-01-09", "source": ["close"]}
  },
  "formula": {"premium": {"op": "premium", "args": ["price", "nav"], "unit": "%"}},
  "conclusion": "收盤 [[price]]，相對淨值的折溢價為 [[premium]]。",
  "metrics": {"收盤": "price", "折溢價": "premium"}
}
```

| 公式 | 參數順序 |
| --- | --- |
| `add`、`subtract`、`multiply`、`divide`、`sum` | 二元運算或加總。可組成季度及年度模型 |
| `premium`、`growth` | 比較值、基準值。結果為百分比數字 |
| `margin`、`allocation`、`eps` | 利益、營收。部位、總額。歸母淨利、稀釋股數 |
| `fx` | 金額、目的幣別／原幣別匯率 |
| `basket_earnings`、`basket_value` | 逐一輸入每單位持股數、EPS 配對，保留虧損。估值輸入整籃獲利、倍數、非股票淨資產 |
| `total_return`、`annualized_return` | 基準價、除息後期末價、累計現金分配。年化多一個年數參數。結果為百分比數字 |
| `bond_value` | 基準淨值、有效存續期間、凸性、殖利率變動小數、情境匯率、基準匯率、未避險比例。匯率方向一致，1 基點填 0.0001 |
| `cash_flow` | 回款、現金成本、資本支出。適用於這三項足以定義的現金流，其他收支調整依模型另列 |

每季保留各自的輸入及計算 ID。年度摘要引用季度結果。拆季、可轉債稀釋、收入認列、回款和費用假設須列明口徑。費用、匯率和配息依各模型口徑計入一次。可用公式連鎖表達其他已定義的計算，估值判斷及假設理由寫在正文。文字與表格中的可重算數值請用 `[[數值ID]]`，實際 ID 使用英數、底線或連字號。取整只影響顯示。預設兩位小數，可用 `precision` 指定輸入、假設或公式的顯示位數，例如淨值保留四位。程式用同一基準價計算三情境的價格漲跌幅，並核對期末價、現金分配和含息報酬是否相符。

`sections` 支援 `data`、`analysis`、`scenarios`、`review`。各區是有順序的區塊陣列。每個區塊有 `type`、`title`，可加 `collapsed: true`。

- `text` 用 `text` 存放文字，換行表示新段。
- `table` 提供 `columns` 及 `rows`，儲存格使用文字或數值引用。
- `chart` 的 `style` 可用 `bar`、`line` 或 `range`。需填 `unit`、`period`、`source`、`labels` 和 `series`。每個系列以名稱對應和標籤等長的數值 ID 陣列，缺點填 `null`。區間圖每點為兩個 ID，可加 `reference` 顯示市價。折線圖可用 `forecast_from` 標出預估起點，並用 `events` 的 `at` 與 `index` 對應標籤及頂層事件索引。

## 更新與相容性

`update` 接受部分 JSON，遞迴合併物件並整組替換陣列。需填新的 `as_of`、`data_cutoff` 及 `update`。市價、公告或匯率更新時，把來源和日期一起換入。陣列若有變動，提交完整新版陣列並確認引用仍相符。程式從合併後的輸入重新計算所有公式，保留未變動的內容。前次論點相關敘述仍須由研究者核對並更新。

工具可讀取舊版未標版本的 `research-data`。直接合併需要結構完整且可重算的第 1 版快照。舊版內容可用於有來源的基線重建。若版型日後變更，歷史 HTML 仍可離線閱讀與擷取。 `verify` 使用當前版型比對成品內容。
