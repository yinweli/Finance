# 研究流程

對 Claude 說「研究 8936」或「研究 0050 8936」，就會自動跑完整個流程，產出 `報告/<代號>/<研究日>.html`。中間不需要切換到 Codex，也不需要再下指令。

## 流程

`工具/run.py` 逐檔依序執行五個步驟。每個需要判斷的步驟都另開一個全新的 AI 工作階段，只讀這一步需要的檔案，所以研究多檔時用量不會累積。

| 步驟 | 執行者 | 產出 | 說明 |
| --- | --- | --- | --- |
| 1. 抓取 | 腳本 `collect.py` | `資料/*.json`、`資料摘要.md`、`上次摘要.md` | 依標的類型抓行情、財報、資產負債與現金流量、籌碼、大盤、美股指數、匯率與殖利率，並算出年化波動度與含息報酬。有上次報告時，擷取上次的結論、期中進度和過去預測的結算結果 |
| 2. 補充 | Claude（Sonnet） | `補充資料.md` | 查法說、新聞、指數規則等腳本抓不到的資料，規則見[補充資料](補充資料.md) |
| 3. 草稿 | Codex（`codex exec`） | `草稿.md` | 依[研究方法](../方法/)、[標的文件](../標的/)與[草稿格式](草稿格式.md)撰寫 |
| 4. 審查 | Claude 審查、Codex 修正 | `審查.md`、`定稿.md` | Claude 依[審查清單](審查清單.md)寫出審查意見與反方論證，Codex 依意見修改出定稿；有阻擋意見時 Claude 再複核一次 |
| 5. 發布 | 腳本 `render.py`、`readme.py` | `報告/<代號>/<研究日>.html`、README 最新報告清單 | 單頁 HTML，圖表由資料直接繪製；README 每檔列最新 3 份，連到 GitHub Pages |

### 自動檢查與重試

- 草稿和定稿都要通過 `check.py`：格式、現價與資料一致、三情境價格順序、機率合計 100、合理區間算式，以及情境機率和歷史基準機率的差距等。不通過時退回 Codex 修正一次。
- 草稿的「資料缺口」中有「可查」而且「影響結論」的項目時，Claude 補查一次，再請 Codex 更新草稿。其餘缺口只列在報告的限制。
- 審查發現方向性錯誤時，第 1 輪可以退回 Codex 修正草稿，第 2 輪審查不可退回。
- 其他失敗，例如 AI 執行錯誤或逾時，每一步自動重試一次。仍失敗就把這一檔標為「待人工」，繼續研究下一檔。
- 額度不足時整批暫停。額度恢復後再執行相同的指令，會從中斷的步驟繼續。

### 預測結算

`run.py` 每次開始前會先執行 `settle.py`：研究日滿 12 個月的舊報告，抓目標日（含）之後第一個收盤價，判斷落在哪個情境，記入 `報告/結算紀錄.json`。2026-11-21 以前的報告另有 6 個月預測，仍會照常結算，統計時和 12 個月分開。結算用目標日的價格，所以多久執行一次都不影響結果。再研究同一檔時，結算結果、期中進度和上次的檢查點會寫進 `上次摘要.md`，由研究者逐項判斷檢查點已達成、落後或尚未到期。

```powershell
python -X utf8 -B 工具/settle.py   # 結算到期報告，並列出各情境平均給的機率與實際命中率
```

同一檔 30 天內的多份報告高度相關，校準統計只取最新一份。

## 權限

| 執行者 | 可以 | 不可以 |
| --- | --- | --- |
| Claude | 讀取專案檔案、上網搜尋與讀取網頁、寫入工作夾 | 執行指令、寫入工作夾以外的位置 |
| Codex | 讀取專案檔案、執行指令（如 `check.py`）、寫入工作夾 | 上網、載入使用者的外掛與 MCP |

Codex 只能根據工作夾內的資料判斷，所以每個數字都能在工作夾找到出處，審查時對得回去。

## 工作夾

每檔每天一個工作夾：`.tmp/工作/<研究日>-<代號>/`。同一天已發布過的標的再研究時，另開 `-v2`、`-v3`。

| 檔案 | 內容 |
| --- | --- |
| `狀態.json` | 各步驟的狀態、Codex 工作階段 ID、最後結果（已發布、待人工、暫停） |
| `資料/` | 腳本抓取的資料，每份一個 JSON，另有 `標的.json` |
| `資料摘要.md` | 給 AI 閱讀的資料摘要 |
| `上次摘要.md` | 上次報告的關鍵數字，沒有上次報告時不產生 |
| `補充資料.md`、`草稿.md`、`審查.md`、`定稿.md` | 各步驟的產出 |
| `執行設定.json` | 程式版本與各角色使用的模型，也會寫進報告 |
| `紀錄/` | 每次呼叫 AI 的提示詞與完整輸出，用來追查問題 |

跨工作夾共用的快取在 `.tmp/快取/`：已過去日期的市場資料、集保股權分散與 ETF 規模的歷史紀錄。快取可以刪除，下次會重新抓取，但集保和規模的歷史紀錄會從頭累積。

## 指令

```powershell
python -X utf8 -B 工具/run.py 8936                # 研究一檔
python -X utf8 -B 工具/run.py 0050 00713 8936     # 依序研究多檔
python -X utf8 -B 工具/run.py 8936 --restart      # 捨棄今天未完成的工作夾，從頭開始
```

單獨執行某一步：

```powershell
$work = '.tmp/工作/2026-11-19-8936'
python -X utf8 -B 工具/collect.py 8936 --work $work   # 只抓資料
python -X utf8 -B 工具/check.py "$work/草稿.md"        # 檢查草稿或定稿
python -X utf8 -B 工具/render.py "$work/定稿.md"       # 產生報告
```

## 新增標的

在 `標的/` 新增 `<代號>.md`，第一行寫 `# <代號> <名稱>`，並列出 `- 類型：個股`（或 `股票ETF`、`債券ETF`）、研究重點、補充搜尋與重估條件重點，格式參考現有檔案。沒有標的文件也能研究：代號以 `00` 開頭視為 ETF（結尾為 `B` 視為債券 ETF），其餘視為個股，只依研究方法通則研究。

ETF 的淨值與持股目前支援元大投信全系列與貝萊德 009826。其他發行商的 ETF 需要在 `工具/fetch_data.py` 新增抓取方式。
